# 0002. 뉴스/SNS·동접자 소스: Steam + 디스패치 + X 공식 API

| 항목 | 내용 |
| --- | --- |
| 상태 | 채택 |
| 날짜 | 2026-10-26 |
| 관련 요구사항 | R-02, R-04, C-02, C-05, C-08 |

## 배경

핵심 기능 3(뉴스/패치노트)과 4의 전체 동접자 시계열을 채울 소스가 필요하다. 비용 0원 지향(C-02), SNS 비공식 수집은 리스크 문서화 후 결정(C-05), 한국어 우선(C-08)이 제약이다. 전체 접속자 수는 소스마다 다르게 나왔다(Arrowhead 행성 합계 55,465, 커뮤니티 API 48,730, Steam은 PS5 제외).

## 고려한 대안

| 대안 | 장점 | 단점 |
| --- | --- | --- |
| Steam `GetNewsForApp` | 키 없음, 0원, 패치노트 태그 | 영어만, 대형 패치에 태그 누락 사례 |
| Steam 뉴스 RSS (`l=koreana`) | Steam 경로 중 유일한 한국어 본문 | 최근 10건만, 태그 없음, ID가 API와 다름 |
| 게임 내 디스패치 | 한국어, 전황 속보 | 패치노트를 대신하지 못함 |
| X 공식 API | 공식 SNS 공지 | 무료 티어 없음(종량제, 월 $1 미만 추정), 카드 등록 필요 |
| X 비공식 수집 | 0원 | 약관이 스크래핑을 명시적으로 금지, 손해배상 조항 → 기각 |
| Reddit | 커뮤니티 공지 | OAuth 승인제, JSON 403, RSS 약 1분 1회 → 기각 |
| Discord 팔로우+봇, YouTube RSS | 0원 | 수동 설정·서버리스 폴링 검증 필요 / 피드 404·500 → 보류 |
| 동접자: Arrowhead 합계 / Steam | 전 플랫폼 / 공식 API·안정적 | 비공식 / PS5 제외 |

## 결정

- **뉴스/패치노트**: Steam `GetNewsForApp`(`feeds=steam_community_announcements`)로 목록을 받고 패치노트를 판별한다(태그 + 제목 버전 패턴). Steam RSS(`l=koreana`)와 제목·게시 시각으로 합쳐, 한국어 번역이 있으면 한국어로 보여준다.
- **속보**: 게임 내 디스패치(ADR 0001의 `NewsFeed`)를 뉴스 피드에 함께 보여준다.
- **X 공식 API를 채택한다** (C-02의 예외). `@helldivers2`의 새 글만 `since_id`로 15분마다 받는다. 예상 비용은 월 $1 미만(추정)이다. 개발자 계정 생성, 결제 수단 등록, 키 발급은 **사용자가 직접** 하고, 키는 Vercel 환경변수(`X_BEARER_TOKEN`)로만 관리한다.
- **전체 동접자 시계열은 Steam `GetNumberOfCurrentPlayers` 값만 쌓는다.** 15분마다 저장하고 화면에 "Steam 기준(PS5 제외)"을 표시한다. 행성별 플레이어 분포(기능 1)는 ADR 0001의 원본 `Status` 값을 쓴다.
- 기각: X 비공식 수집, Reddit. 보류: Discord, YouTube RSS(필요해지면 새 ADR).

## 결과

- 이점: 뉴스 경로는 0원·키 없음이고, 한국어 패치노트가 있으면 한국어로 보여준다. 공식 SNS 공지도 포함한다.
- 감수하는 비용·리스크와 대응:
  - X API는 유료이고 요금 정책이 자주 바뀌었다 → X 개발자 콘솔에 지출 상한을 설정한다(사용자). 비용이 오르거나 키가 없으면 X 섹션만 숨기고 나머지는 계속 동작하게 만든다.
  - 빈 응답 폴링의 과금 여부와 엔드포인트별 요청 한도를 확인하지 못했다 → P2에서 첫 과금 내역을 보고 폴링 주기를 조정한다(필요하면 1시간).
  - Steam 동접자는 PS5를 빼므로 실제 전체 인원보다 적다 → 화면에 기준을 명시한다.
  - RSS는 최근 10건만 준다 → 15분 수집으로 놓치지 않게 DB에 쌓는다.
- 후속 작업: E-03 `.env.example`에 `X_BEARER_TOKEN` 추가, E-04 스모크 테스트에 Steam 호출 1건.
