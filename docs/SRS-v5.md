### U-04 카드 구성

| 순서 | 내용 | 데이터 |
| --- | --- | --- |
| 1 | 머리: 종류(해방 / 방어), 오른쪽에 예상 시각(U-05). 방어는 남은 시간도 | `Front.defense`, U-05 |
| 2 | 행성 이름(공식 한국어 + "(원문)"), 섹터 · 세력, 주요 명령 대상 표시 | `Front.name`·`nameEn`·`sector`·`faction`, `assignment` 대상 행성 |
| 3 | 진행 막대 (해방은 세력 색, 방어는 info) | `Front.progress` |
| 4 | 진행률 소수 4자리(`62.3412% 해방` / `22.5030% 방어`) + 시간당 변화(`+0.7%/h`) | `Front.progress`, `Front.perHour` |
| 5 | 투입 인원과 전체 투입 인원 대비 비율(`26,568명 · 39%`) | `Front.players`, `WarOverview.totals.players` |

카드는 정보만 보여 주고 링크가 없다. 수치는 모두 글자로도 나온다(막대만으로 전달하지 않음, Q-03).

### U-05 예상 시각 규칙

기준 시각은 수집 슬롯(`WarOverview.slot`)이다. 서버가 예상 시각(ISO)을 계산해 넘기고, 화면은 브라우저 시계로 남은 시간("2일 5시간")을 그린다(SRS v4 §3 "현재 시각이 필요한 표시는 클라이언트에서").

| 상황 | 표시 |
| --- | --- |
| 해방, 시간당 변화 > 0 | 100%까지 걸리는 시간 → "해방 예상 N" |
| 해방, 시간당 변화 < 0 | 0%까지 걸리는 시간 → "철수 예상 N" |
| 해방, 시간당 변화 0 또는 기록 없음 | "정체" |
| 방어, 이미 100% | "방어 성공" |
| 방어, 100% 도달 예상이 종료 시각 전 | "방어 예상 N" |
| 방어, 종료 시각까지 100%에 못 미침(속도 ≤ 0, 기록 없음 포함) | "실패 예상" |

방어 카드는 머리 오른쪽에 남은 시간(`HH:MM:SS`, 강조색)을 함께 보여 준다.

## 3. 배치·접근성

- 홈: 헤더 + KPI → [은하계 지도 | 주요 명령] → **주요 전선 카드(전체 폭)** → **업데이트 내역(전체 폭)** → 출처 한 줄.
- 카드 그리드는 칸 최소 300px 자동 채움: 1440px에서 4열 × 2행, 좁은 화면에서 1열. 360~1440px 가로 스크롤 없음(Q-04).
- 카드 안의 "(원문)" 버튼만 포커스를 받는다. 포커스는 accent 1px 외곽선(Q-03).
